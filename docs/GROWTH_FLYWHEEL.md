# Shroom 用户增长与复利战略

> 状态：增长与商业化方向基线
>
> 更新：2026-09-16
>
> 目的：让 Shroom 的长期个人价值、外部传播和可信关系形成同一条可验证闭环，而不是依赖功能数量或日记数量制造增长感。

## 1. 核心判断

Shroom 的长期优势不是“AI 会写日记”或“AI 记得更多”，而是：

> 以用户私有、可追溯的真实人生记录为根，把其中经过用户确认的部分转化为真实表达、可信档案、共同经历与可验证成果。

通用长期记忆会逐渐成为模型和操作系统的基础能力。Shroom 必须把长期记忆继续转化为三种更难被替代的价值：

1. **私人复利**：过去的经历让未来的判断、提醒和行动更准确；
2. **传播复利**：真实生活持续产生可公开、可跨平台保存的表达；
3. **关系复利**：共同经历和真实结果形成新的信任与机会，并反过来补充人生数据库。

## 2. 三条飞轮

### 2.1 私人价值飞轮

```text
记录真实经历
  → AI 提取候选理解与线索
  → 用户确认、纠正或拒绝
  → 在未来相关情境中被找回
  → 用户反馈是否有帮助
  → 记忆、判断和提醒逐渐更准确
```

这条飞轮产生留存和付费价值，但本身不会自动带来新用户。

### 2.2 真实表达与分发飞轮

```text
私人日记 / 行动 / 项目结果
  → AI 生成有来源的表达候选
  → 用户编辑并明确公开
  → 发布到个人活档案和外部平台
  → 访客阅读、提问、引用或发起连接
  → 新互动和反馈回到用户的数据空间
  → 下一次表达更真实、更准确
```

公开内容必须能解释“来自哪些已授权事实”，不得为了传播捏造经历、人设、结果或观点。第一阶段只生成候选和复制稿，不自动代发。

### 2.3 可信关系与成果飞轮

```text
公开活档案带来认识或合作
  → 用户邀请对方进入一个具体关系/项目上下文
  → 双方记录承诺、过程与结果
  → 双方确认一项具体事实或成果
  → 可信证据进入各自档案
  → 后续匹配、合作与公开表达更可信
  → 带来新的关系和机会
```

Shroom 不给人生成全局信用分，也不判断“一个人好不好”。可信证明只针对具体事实、具体共同经历和具体结果，并保留确认方、时间和适用边界。

## 3. 产品结构

### 3.1 私人真实层

包括日记、回看、未解之问、身心记录、人脉、待办、复利系统、人生 OS、外部活动和用户反馈。默认私密，是所有派生价值的事实根。

### 3.2 用户授权的表达层

包括真实表达候选、跨平台内容母稿、公开活档案、公开版个人 AI 和用户选择公开的经历/理解。任何内容从私人层进入这一层都必须经过用户确认。

### 3.3 共同证据层

包括合作邀请、共同经历、事实确认、成果确认和后续反馈。原始私人记录不因共同确认而公开；双方只确认经过裁剪的事实陈述。

## 4. 方向优先级

### 当前主线

1. **真实表达代理**：从日记、行动和项目结果生成有来源的表达候选；
2. **跨平台人生内容母库**：保存用户最终确认的版本，不依赖某个社交平台；
3. **公开活档案**：展示用户主动公开的经历、项目、关注方向和可信结果；
4. **合作成果确认**：用具体共同结果替代抽象信用分。

### 值得单独验证的相邻方向

- **家庭记忆与人生传记**：语音讲述、家庭提问、共同补充、数字/实体传记；天然具有赠送和邀请路径；
- **决策—行动—结果案例**：用户公开一个可脱敏的长期案例，持续补充后来发生了什么；
- **专业上下文包**：用户向教练、医生、咨询师或招聘方分享限时、限范围的相关资料；
- **能力证明**：未来与 EvoX 的独立能力 Evidence 结合，不把自我陈述冒充验证结果。

### 暂不进入当前主线

- 泛日记信息流；
- 自动发布社交媒体；
- 全局信用评分；
- 基于私密日记直接进行交友或招聘排序；
- 健康诊断和治疗建议；
- 在没有真实使用方之前建设通用个人数据 API 或开放平台。

## 5. 增长的判断标准

以下信号必须分开统计：

| 阶段 | 应验证的真实结果 | 不能冒充结果的数字 |
|---|---|---|
| 私人价值 | 用户再次使用过去记忆并确认有帮助 | 日记总数、AI 调用次数 |
| 真实表达 | 用户主动采纳、编辑并实际公开 | 生成稿件数量 |
| 外部触达 | 外部访客进入公开档案并发生有效互动 | 单纯页面浏览量 |
| 邀请 | 被邀请者完成查看、回应或共同确认 | 邀请链接发送量 |
| 信任 | 共同确认的具体成果带来后续合作或机会 | 共鸣、点赞总数 |
| 收入 | 用户因持续价值付费并留存 | 充值页面访问量 |

在真实用户验证前，不把任何飞轮写成“已经成立”。

## 6. 首个可验证闭环

首批目标用户假设为创作者、创业者、自由职业者和多项目经营者。最小闭环只包含：

1. 每周生成一次有来源的“真实表达包”；
2. 用户选择一条编辑并公开；
3. 内容进入自己的公开活档案，并可复制到外部平台；
4. 访客可以提问、关注或发起合作；
5. 完成一次合作后，双方可确认一项具体成果；
6. 新证据回到用户的私人数据库，改善后续表达与判断。

首轮验证重点不是做全，而是确认四件事：用户是否愿意持续公开、公开内容是否带来有效互动、外部人是否愿意参与、双方确认的结果是否真的提高信任。

## 7. 商业化原则

- 免费层负责记录入口、基本公开档案和传播；
- 订阅价值来自长期记忆、回看、真实表达辅助、主动提醒和高级档案能力；
- 家庭传记可采用年度项目或一次性数字/实体交付；
- 专业协作和能力证明只有在真实机构采用后再设计 B2B 收费；
- 不出售私人日记，不以敏感个人数据投放广告，不通过制造焦虑促进付费。
