**工程与输出契约通过；产品价值尚待用户完成五组盲评，因此 v5 继续保持只读、默认关闭，不进入本人账号受控试用，也不部署。**

本轮冻结 `analysis-b2-experiment-v5-loss-path`。没有换模型、扩展架构或继续改写提示词，只修复验收中定位到的一处共享证据校验缺陷：模型返回的逐字原文若包含连续空格，旧校验器会先把空格压缩，再与未压缩的日记正文匹配，导致真实候选被误删。修复后校验保留原始空格，仍要求证据是日记中的连续逐字片段。

生产 `https://shroom.evox.run/` 仍使用 A1。本轮没有部署、没有批量重分析历史日记，也没有把任何实验结果写入待办、菇卡、身心记录、未解之问、复利系统、搜索、统计或发现。

- 两组均固定后才运行 A1 与 v5；完整请求和输出保存在 Git 忽略的私密目录，权限为 `0600`。

## 两个语义边界的实测

### “体重变化是很大问题”

v5 保留为身体观察候选：“体重变化被自己列为冲浪进步慢的问题之一”，状态为 `UNCERTAIN`；`measurements` 为空，同时把“具体数值、时间跨度和方向”列为缺失信息。它没有补成增重、减重或近期异常波动。

### “我应该多问问”

v5 生成“联系一位旧友，问问他有没有可以一起做的事”的待确认候选，`dueDate=null`。它仍是候选，不是已经决定、已经完成或已创建的事实；页面默认不勾选。

## 验收中修复的明确缺陷

一篇未见样本的原文包含连续空格。模型原始返回了三条有逐字依据的心理观察，旧校验器只留下了一条。原因不是模型遗漏，而是 `groundedExcerpt` 先压缩候选证据空格，再对未压缩原文做 `includes`。

最小修复只改变证据字符串的匹配方式：保留模型返回的原始空格并要求其完整出现在日记正文中。新增回归测试后，三条均被保留；不存在的摘录仍会被拒绝。没有放宽其他证据规则，也没有修改提示词。

## 仍未通过的产品判断

契约修好不等于分析已经更有价值。本轮真实输出仍出现三类明确问题：

1. 一篇轻松记录具体事件的积极日记，v5 仍生成了一条几乎只复述事件的“首屏理解”。它没有明显错误，但也没有提供足以证明值得占据首屏的认知增量。
2. 一篇多主题月度复盘生成了两个高度接近的未解之问，都在追问忙碌/自动化是否推进长期方向。数量满足上限，但没有真正完成语义去重。
3. 一篇工作日记已经明确写出“明天是否继续做，答案是不要”，v5 又生成“确认明天是否继续并给出决定”的待办。它仍是未选候选、没有造成正式写入，但把已表达的答案重新包装成未决任务，属于信息性质保留不足。

另外，回归集 20/20、未见集 5/5 都返回非空综合。此前普通散步负控制曾 3/3 正确返回明确空结果，说明空输出链路可用；但本轮的简单积极事件表明“允许为空”尚未稳定转化为产品层面的克制。

因此，本轮不以“字段完整”和“Token 更少”替代产品验收，也不因为 v5 候选总数少于 A1 就宣称质量更高。用户需要直接阅读真实对照，判断忠实度、理解价值、有效信息保留和阅读体验。
