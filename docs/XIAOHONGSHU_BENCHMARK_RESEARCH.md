# Shroom 小红书官方账号持续流量研究

> 首轮截止：2026-09-18  
> 状态：`PARTIALLY_VERIFIED`  
> 研究对象：今年仍有可核验流量信号的官方/品牌账号，而不是历史案例文章中的旧爆文

## 1. 先把“爆文”拆成两个不同问题

1. **账号级持续流量**：同一账号是否在多个时间窗口持续出现可观察增长；
2. **笔记级爆发**：某篇具体笔记是否显著超过该账号自身基线，并能排除投流、热点事件和品牌体量等干扰。

公开榜单只能证明账号在一个时间窗内出现粉丝增长，不能证明某篇内容自然爆发，更不能证明增长由某个版式或标题造成。笔记级结论必须保留笔记 URL、发布时间、可见互动快照、账号基线和多个观察节点。

## 2. 证据门槛

### 来源优先级

1. 小红书笔记和账号直接页面；
2. 小红书官方工具或账号后台的一方数据；
3. 可回溯日期与指标的第三方榜单；
4. 媒体、服务商或营销案例文章。

第 4 类不能单独进入验证结论。当前小红书开放平台只开放 `basic_info`，`user_profile` 与 `read_notes` 仍在规划中，因此公开账号研究暂时必须采用人工可复核页面与第三方时间序列，不能伪装成官方 API 自动审计。

### 分级

| 等级 | 门槛 | 能说什么 |
|---|---|---|
| `CURRENT_SUSTAINED` | 官方身份；今年至少 3 个不同月份；最近 14 天内有数据；最近至少 2 个连续窗口 | 账号今年持续且当前仍有流量信号 |
| `YEAR_REPEAT` | 官方身份；今年至少 3 个不同月份，但缺最新连续窗口 | 今年多次出现，当前状态待复核 |
| `RECENT_REPEAT` | 最近至少 2 个连续窗口，但尚未覆盖 3 个月 | 最近连续增长，尚不能称全年持续 |
| `WATCHLIST` | 单窗口、身份或来源仍需补证 | 只能继续观察 |

任何等级都不自动等于“爆文”。

## 4. 对 Shroom 有用的结论

### 已验证

- **持续性必须看时间序列。** Apple 在 6 月、8 月和 9 月均有增长记录，并在最近连续窗口继续出现；这比一篇“某品牌曾经爆过”的案例文章更可信。
- **不能从账号增长倒推出具体创意机制。** 当前数据能支持“账号仍有增长”，不能支持“某种封面、标题或文案导致增长”。
- **先建立自身基线。** Shroom 必须用同一账号、连续内容编号和 2h / 24h / 72h / 7d 快照，才可能判断某篇是否显著超过自身基线。

### 待笔记级审计的假设

- 品牌账号更可能依靠可识别的长期栏目、角色或产品场景积累，而不是每次更换一套漂亮海报；
- 大品牌、热门游戏和强角色 IP 的增长机制不能直接迁移给 Shroom；
- 对 Shroom 更可能可迁移的是：固定栏目、具体困惑、真实产品过程、可核验结果、评论进入下一期，而不是品牌体量与热点预算。

这些仍是研究假设，不是本轮已验证结论。

## 5. 下一轮研究动作

每周只做增量：

1. 更新候选账号最近一个周窗口，过期 14 天即降级；
2. 只为通过账号级门槛的账号抽取 10 篇同栏目笔记；
3. 记录笔记 URL、发布时间、内容类型、首屏、互动快照和观察时间；
4. 用账号自身中位数作基线，不拿大号绝对互动量与 Shroom 比；
5. 区分可迁移机制与不可迁移资产；
6. 将一个可迁移机制交给内容生成 Agent 做单变量测试。

在完成第 2—4 步前，系统不会输出“顶级爆文模板”或“爆文概率”。
