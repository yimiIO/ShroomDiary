# Shroom 品牌色与视觉识别系统

> 定标版本：2026-09-18 v1  
> 状态：品牌色定标；十套宣发候选待 CEO 选择内容方向  
> 核心定位：可信的个人记忆与辅助系统

## 1. 不是“绿色日记”，而是“让记忆重新产生作用”

Shroom 的视觉不能只表达自然、治愈或蘑菇。那些符号容易好看，却无法说明产品的独特价值。品牌必须同时让人感到四件事：

1. **私人真实**：像纸、日记和个人档案，不像公共信息流；
2. **可信判断**：AI 会寻找来源、变化和反例，不用漂亮话替用户下结论；
3. **活的记忆**：过去不是尘封资料，而会在此刻重新亮起来；
4. **人的决定权**：系统帮助找回，意义和行动仍由用户决定。

因此品牌色的角色不是“森林配色”，而是：

> 深色负责可信与判断；纸色负责私人记录；记忆亮色负责找回；珊瑚色只负责证据冲突。

## 2. 当前资产审计

### 已形成的产品颜色

对当前 Shroom 页面与组件的十六进制颜色进行统计后，使用最稳定的是：

- `#172019`：出现 142 次，承担正文、深色面板、主按钮和选中态；
- `#F1F8E9`：出现 82 次，承担页面背景；
- `#DDEC8C`：已经用于进度、重点数字和柔和操作；
- `#42634A / #5D7562 / #59655C`：承担支持层级与可读正文；
- `#D86246 / #A45E50`：已经用于异常、冲突和警示语义。

这说明产品已经自然长出了一套“深菌丝绿 + 雾纸绿 + 记忆黄绿”的品牌胚胎，不需要另起炉灶。

### 图标现状

底部导航图标仍是旧资产：未选中主色分别接近 `#85888E / #707070 / #71757C`，选中图标接近 `#333333 / #000000`；它们没有使用当前页面的 `#172019` 与 `#718075`，应视为待迁移资产，而不是品牌依据。

`src/manifest.json` 声明了 `unpackage/res/icons/1024x1024.png` 等 App 图标，但文件未进入当前仓库，线上 H5 也没有 favicon。正式 App 图标源文件因此处于 `MISSING_SOURCE`，不能声称已经完成颜色审计。

建议最终 App 图标固定为：`#172019` 底、`#FFFDF7` 菇体或记忆卡片、`#DDEC8C` 记忆标签，`#D86246` 最多只做一个极小证据点。

### 2026-09-18 品牌 Agent 决断：背景绿与菇形

用户反馈“背景绿色更好、logo 的菇和封面小蘑菇不一样”后，品牌优先级更新为：

1. **正式 logo / App 图标源文件优先于宣发角色。** 在正式源文件缺失前，任何封面里的“菇”都只能是临时记忆符号，不能定义成固定 IP，也不能反向影响 logo。
2. **官方宣发背景采用 Brand Paper `#E9F1E1`。** 它来自产品七日分享页的真实背景，比 `#F1F8E9` 更有品牌存在感；`#F1F8E9` 保留为 App 常规页面底色。
3. **封面暂不使用有表情的小脸蘑菇作为主角。** 直到正式 logo 源文件补齐，宣发可以使用无脸菇形轮廓、记忆卡片、证据线和档案物件；不要把临时吉祥物做成品牌中心。

## 3. 正式核心色

| 角色 | 名称 | 色值 | 品牌含义 | 主要用途 |
|---|---|---|---|---|
| 核心锚点 | 菌丝墨绿 Mycelium Ink | `#172019` | 可信、隐私、判断、长期性 | Logo 底、正文、主按钮、深色面板 |
| 品牌场域 | 活纸雾绿 Living Paper | `#F1F8E9` | 私人纸张、呼吸感、非临床 | App 页面、常规宣传底色 |
| 记忆信号 | 记忆黄绿 Memory Lime | `#DDEC8C` | 一条过去信息重新被找回 | 重点数字、标签、柔和 CTA、角色记忆标签 |
| 人的温度 | 暖纸白 Warm Paper | `#FFFDF7` | 人写下的真实，不是冷数据 | 卡片、长文、菇体和纸张 |
| 证据冲突 | 证据珊瑚 Evidence Coral | `#D86246` | 反例、变化、值得核对 | 小面积证据点、冲突标注 |

这五个颜色已经足够构成品牌识别。其他颜色必须是它们的层级色，而不是为了每个页面“再找一个好看的绿”。

## 4. 产品色与传播色的关系

`#DDEC8C` 是产品里的正式记忆亮色。小红书封面使用的 `#DDEC4A` 不应伪装成同一个颜色，它被正式定义为 **Memory Flash / 传播闪色**：

- 只用于信息流封面、线下大字和短期活动；
- 单张画面占比不超过 25%；
- 必须和 `#172019` 配对；
- 不用于 App 大面积背景，也不用于小字号正文；
- 传播内容进入产品截图时恢复为 `#DDEC8C`。

这样既保留传播停留力，也不会让产品和官方账号看起来像两个品牌。

## 6. 可读性门禁

WCAG 2.2 对普通文字要求至少 `4.5:1`，大字至少 `3:1`。Shroom 固定允许的主要组合：

| 前景 / 背景 | 对比度 | 结论 |
|---|---:|---|
| `#172019` / `#F1F8E9` | 15.39 | AAA |
| `#172019` / `#E9F1E1` | 14.43 | AAA，官方宣发底色 |
| `#172019` / `#DDEC8C` | 13.09 | AAA |
| `#172019` / `#DDEC4A` | 12.86 | AAA |
| `#59655C` / `#F1F8E9` | 5.62 | AA |
| `#59655C` / `#E9F1E1` | 5.27 | AA |
| `#FFFFFF` / `#42634A` | 6.74 | AA |
| `#172019` / `#D86246` | 4.58 | AA |
| `#FFFDF7` / `#A45E50` | 4.81 | AA |
| `#718075` / `#F1F8E9` | 3.83 | 只允许大字、元信息或非正文 |
| `#718075` / `#E9F1E1` | 3.59 | 只允许大字、元信息或非正文 |

颜色不能单独承担“确认、危险、待核对”等含义，必须同时出现文字或形状。参考：[W3C WCAG 2.2 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

## 7. 官方账号识别资产

顶级品牌不会让颜色独自承担全部识别。Duolingo 的官方规范明确把核心绿、文字色、背景色与固定角色共同使用；Mozilla 也把颜色定义为命名 Token，要求整个系统复用而不是随意取色。Shroom 对应的固定资产是：

1. 菌丝墨绿；
2. 记忆标签黄绿；
3. 无字记忆卡片；
4. “记忆管理员菇”；
5. 找 / 对 / 问 / 停四个动作；
6. 重要判断回到日期、原文、变化与反例的表达结构。

参考：[Duolingo 官方色彩规范](https://design.duolingo.com/identity/color/1000)、[Mozilla Protocol 色彩 Token](https://protocol.mozilla.org/docs/fundamentals/color)。

## 8. 颜色比例

### 产品界面

- 65%—75%：Living Paper、Warm Paper 等表面；
- 15%—25%：Mycelium Ink 与深色层级；
- 5%—10%：Memory Lime；
- 0%—3%：Evidence Coral。

### 品牌宣发

- 每张封面必须至少出现 Mycelium Ink 与一种纸色；
- 官方账号封面优先使用 Brand Paper `#E9F1E1`，而不是产品常规页面底色 `#F1F8E9`；
- Memory Flash 最多占 25%，不得整版荧光；
- Evidence Coral 最多占 5%，只标记一个冲突；
- 每张只允许一个视觉事件和一个高亮色块；
- 即使去掉 `SHROOM` 字样，仍应通过颜色、记忆标签和卡片动作识别。

## 9. 明确禁止

- 大面积“疗愈薄荷绿”，会把产品误读成冥想或健康 App；
- 黑底荧光绿铺满全屏，会变成 Web3、游戏或 AI 工具；
- 每个栏目使用一套完全不同的颜色；
- 珊瑚色承担装饰而非证据语义；
- 用 `#718075` 在浅底上排小字号正文；
- 用旧灰黑导航图标继续代表正式品牌；
- 在正式 App 图标源文件缺失时凭截图猜测并覆盖。

## 10. 结论

Shroom 的品牌色正式确定为：

> **菌丝墨绿 `#172019` + 活纸雾绿 `#F1F8E9` + 记忆黄绿 `#DDEC8C` + 暖纸白 `#FFFDF7` + 小面积证据珊瑚 `#D86246`。**

传播闪色 `#DDEC4A` 是受控扩展，不是产品基础色。品牌升级的下一步不是再选颜色，而是补齐正式 App 图标源文件、统一旧导航图标，并让所有对外内容连续使用同一组识别资产。
