# Shroom 品牌形象 Agent 决策

> 版本：2026-09-18 v1  
> 状态：品牌形象方向内审，非商标法律意见  
> 触发原因：现有头像亲和但过于简单，封面小脸蘑菇与头像不一致，且普通蘑菇图形显著性不足。

## 1. 核心判断

Shroom 不能把“头像、商标图形、运营角色”混成一个东西。

- **头像**：负责亲和、用户第一眼不反感，可以简单；
- **商标图形**：负责可注册、可防守、可缩小识别，必须有独有结构；
- **运营角色**：负责内容表达、动作和情绪，可以更丰富，但必须服从商标图形。

因此，接下来不应该继续把一个可爱的蘑菇头像放大成完整品牌系统。正确方向是：

> 保留头像的菇形亲缘，但给商标图形加入 Shroom 独有的“记忆结构”。

## 2. 商标显著性边界

这不是法律意见；正式申请前仍需商标代理做近似检索、分类判断和提交策略。

但设计上必须避开低显著性风险。国家知识产权局公开的《商标法》第十一条明确，只有通用名称、通用图形，或仅直接表示商品功能、用途等特点的标志，不得作为商标注册；商标注册还需要有显著特征、便于识别。参考：国家知识产权局《中华人民共和国商标法（2019年修正）》。

对 Shroom 来说：

- 单纯“蘑菇图形”风险高，因为它接近产品名的直译图形；
- 单纯“日记本/卡片”风险高，因为它直接描述记录工具；
- 单纯“AI 对话气泡”风险高，因为它是行业通用符号；
- “蘑菇 + 记忆缺口 / S 形负空间 / 折角卡片 / 菌丝节点”的组合显著性更好。

## 3. 设计原则

### 必须保留

1. 与头像有亲缘：保留菇盖、菇柄、右上记忆标签或缺口；
2. 可小尺寸识别：64px 仍能分出轮廓；
3. 单色可用：去掉颜色后仍有结构；
4. 不像医疗、游戏、Web3、冥想或普通手账；
5. 能延展到 App icon、小红书封面、启动页、菇卡水印和导出报告。

### 必须加入

1. **记忆结构**：缺口、折角、档案门、证据线或菌丝节点；
2. **非对称性**：不能是普通圆头蘑菇；
3. **Shroom 线索**：最好有 S 形、记忆标签或卡片折角之一。

## 4. 六个方向

总览图：`artifacts/brand/shroom-identity-concepts/contact-sheet.png`

| 编号 | 方向 | 评估 |
|---|---|---|
| 01 | 头像亲缘 · 记忆缺口 | 最贴合现头像，但显著性仍偏弱，适合头像升级，不适合单独主商标 |
| 02 | S 形负空间 | 最推荐；菇形、Shroom 首字母和记忆缺口三者结合，显著性强 |
| 03 | 档案门菌盖 | 产品意义强，但图形偏“纸张/档案”，需要继续简化 |
| 04 | 菌丝记忆节点 | 很贴合 AI 记忆产品，但小尺寸略复杂，适合二级视觉语言 |
| 05 | 折角卡片菇 | 第二推荐；最贴合“日记 + 菇”，适合 App icon 与商标并行测试 |
| 06 | 印章式 S 菇 | 显著性强，但离现头像最远，适合作为注册备选或企业级标识 |

## 5. 品牌 Agent 推荐

主推两条路线：

1. **02 S 形负空间**：作为商标主方向。它最不像普通蘑菇，也能解释为 Shroom、记忆路径和个人数据库。
2. **05 折角卡片菇**：作为 App icon 主方向候选。它更亲和，也更接近用户理解的“日记”。

保留一个防守备选：

3. **06 印章式 S 菇**：如果 02 或 05 近似检索风险较高，用它做更强显著性备选。

## 6. 下一步

1. 从 02、05、06 中选 1 个主方向、1 个备选方向；
2. 为选中的方向做黑白版、反白版、16px/32px/64px 缩小测试；
3. 做第 9、35、38、41、42 类商标近似检索；
4. 再决定 App icon、公众号头像、小红书头像和品牌水印的统一版本。

当前不建议继续用“小脸蘑菇”做正式品牌形象。它可以作为早期运营插画，但不能作为商标级资产。
