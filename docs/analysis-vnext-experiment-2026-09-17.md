# Shroom 日记分析 vNext 隔离实验报告（2026-09-17）

## 结论

`analysis_vNext` 暂不接入生产分析路径。

当前模型 `deepseek-v4-flash` 配合 vNext 协议（B 组）在本轮样本中最能区分原始表达、事实、用户自己的解释和 AI 推断，也更善于保留反例与不确定性。但它的平均 Token 是当前生产提示词的 1.94 倍，综合结果平均达到 7.65 条，阅读负担明显偏高。候选 Pro 模型没有带来足以抵消成本和稳定性损失的质量提升。

因此本轮只上线已经独立验证的明确缺陷补丁，不启用 vNext：

- AI 候选待办默认不勾选；
- 未经用户确认的 AI Life OS / 复利关联保持 `PENDING`，不再成为正式关系；
- 用户采纳状态与信息证据性质分离；
- 身心复核页面如实说明独立模型调用与成本；
- 移除会强迫模型给普通经历贴生物驱动标签的冲突要求；
- 空数组可沿链路保留，不用默认文案伪造洞察。

## 实验范围

- 私密历史日记：20 篇；
- 类型覆盖：关系 4、工作 3、健康 3、财务 1、积极经历 3、普通经历 3、多主题 3；
- 每篇固定同一份重建上下文，各组之间不共享实验输出；
- 每组运行 5 个观察席和 1 次综合，共 6 次调用；
- 正式数据库只读，实验输出不进入搜索、统计、发现或用户知识；
- 本轮属于“基于重建上下文的对照”，不是对历史生产时刻的精确重放；
- 私密原文与完整输出只保存在 Git 忽略目录 `server/.local/analysis-vnext/20260917-full-20/`。

## 内容对比

以下判断来自 Codex 对匿名类别样本的复核，不是已经与多名真实用户校准过的盲评结论。

| 样本类型 | B 组相对当前方案的主要改善 | 仍存在的问题 |
| --- | --- | --- |
| 关系 | 能把对他人动机的猜测与对方实际表达分开，也能同时保留想连接和想独处两个方向 | 综合层重复观察席结论，文字偏长 |
| 工作 | 能识别“人类天生反感更新”缺少证据，并区分灰度节奏与责任分配 | 对同一张力从多个视角重复解释 |
| 健康 | 能把单一激素解释保持为假设，不把心理或行为现象升级成医学事实 | 缺少真正的身心候选保留链路对照 |
| 财务 | 能区分痛苦、解释、计划和已完成行为，并指出规则是否真实运行仍缺证据 | 单篇内容较长时，补充洞察数量膨胀 |
| 普通经历 | 能保留用户对字面神迹与象征意义的不同态度，不再粗暴概括为单一信仰立场 | 部分推理对普通游记仍显得过度分析 |
| 积极经历 | 能分开事实、感受、自我标签和行动计划 | 对无需深挖的内容也容易给满额洞察 |
| 多主题 | 能保留多个主题和不确定性，不把生理解释、他人评价或未来规则写成事实 | 首屏之外仍有过多补充项 |

当前生产提示词在这 20 篇日记中生成了 16 个待办、29 个未解之问、9 个菇卡建议和 96 条身心结构项。Pro + 当前提示词仍生成 21 个待办、20 个未解之问、9 个菇卡建议和 60 条身心结构项。更换模型本身没有消除过度生成问题。

vNext 的综合层固定输出 2 条主要理解，但 B 组平均还有 5.65 条补充理解、21.35 条观察席内部观察；D 组平均有 8.15 条补充理解。它证明了“可以更忠实”，还没有证明“已经适合产品首屏”。

## 为什么暂不上线

1. B 组成本约为 A 组的 1.96 倍，平均耗时约为 1.75 倍。
2. Pro 组成本更高、耗时更长，并出现一次结构化输出失败，没有体现稳定优势。
3. vNext 实验只比较理解协议，没有同时生成正式的待办、菇卡、未解之问和身心候选，尚不能证明有效信息不会丢失。
4. 20 篇单次运行可以发现明显缺陷，不能证明跨用户稳定改善；关键样本还需要重复运行和真实人工盲评。
5. “错误更少”部分来自输出更克制，不能用少说话掩盖应保留信息的缺失。

## 下一轮最小实验

- 以 B 组为基础，不再优先尝试 Pro；
- 每个观察席最多保留 1—2 条真正新增的观察，不适用时返回空数组；
- 综合首屏保持 0—2 条主要理解，补充理解最多 2 条且不得复述主要理解；
- 原始观察可以保存为实验追踪证据，但不全部展示给用户；
- 在同一次隔离运行中补回待办、菇卡、未解之问、身心候选，逐项验证“该保留的没有丢、未经采纳的不入正式状态”；
- 对关键错误样本重复运行，并邀请人工对匿名乱序输出校准四个维度：忠实度、理解价值、有效信息保留、阅读体验；
- 通过状态测试和纵向测试后，只进入小范围受控试用，不自动重分析历史数据。
