# Shroom 小红书热点与官方账号视觉系统

> 版本：v2，2026-09-18  
> 目的：修正首轮图文“可信但不吸引、统一但不识别”的问题  
> 当前状态：机制与封面样稿已验证；尚未发布

品牌色以 [`SHROOM_BRAND_SYSTEM.md`](./SHROOM_BRAND_SYSTEM.md) 为准：菌丝墨绿 `#172019`、官方宣发底色 Brand Paper `#E9F1E1`、App 常规底色活纸雾绿 `#F1F8E9`、记忆黄绿 `#DDEC8C`、暖纸白 `#FFFDF7`、小面积证据珊瑚 `#D86246`。`Memory Flash #DDEC4A` 只是信息流封面的受控传播闪色，不是 App 基础色。

## 1. 上一版错在哪里

上一版只迁移了 flomo 的克制、Apple 的单一信息和丁香园的证据边界，却没有真正迁移官方账号形成记忆的机制：

1. 没有固定主角。每篇只剩排版，用户划过后记不住是谁说的；
2. 没有视觉事件。大量空白、说明文字和小卡片像报告，不像信息流内容；
3. 没有情绪反应。标题有问题，画面却没有角色态度与冲突；
4. 没有热点接口。内容只从产品功能内部出发，缺少用户正在讨论的入口；
5. 把“同一模板”误当成“品牌识别”。真正的识别来自固定角色、固定行为、固定物件和固定声音。

## 2. 标杆机制如何真正落到 Shroom

| 标杆 | 真正迁移的机制 | Shroom 实现 |
|---|---|---|
| 多邻国 | 固定 IP 对外界事件做连续反应 | “记忆管理员菇”每篇出镜，并保持怀疑、找证据、翻旧记录三种固定行为 |
| 百度地图 | 一个具体生活时刻只证明一个功能 | “AI 说我总在逃避，但三个月前的日记不同意” |
| 蚂蚁森林 | 把长期积累变成可见对象 | 每条历史记录统一成为可抽取、连接、积累的“记忆卡片” |
| Apple | 强主体、少信息、功能本身成为画面 | 封面只保留一个冲突、一个角色动作、一句判断 |
| flomo | 方法与真实用户经验长期供给 | 内页回到原文、日期、方法、用户投稿和实际记录场景 |

多邻国公开访谈把“官方账号作为据点、撬动自传播”与固定角色结合；Shroom 不复制催打卡和疯癫语气，只迁移“稳定角色 + 对当下事件作出品牌独有反应”。参考：https://www.digitaling.com/articles/1272949.html

## 3. 品牌角色与 logo 一致性

角色名：**记忆管理员菇**。

2026-09-18 决断：正式 logo / App 图标源文件尚未补齐，且用户指出 logo 的菇形与当前小脸蘑菇不一致。因此“记忆管理员菇”暂时降级为**临时记忆符号**，不能作为正式固定 IP 对外强化。官方账号现阶段优先使用无脸菇形轮廓、记忆卡片、证据线、档案盒等资产；等正式 logo 源文件补齐后再统一角色。

固定外形：

- 深森林绿、不对称的大菌盖；
- 菌盖右侧固定一张荧光黄绿“记忆标签”；
- 暖白身体、黑色椭圆眼睛；
- 眉毛承担情绪，不依赖嘴部表情；
- 一次只携带一种工具：记忆卡片、放大镜、档案盒或证据线。

固定人格：认真、怀疑、略带冷幽默；会找证据，但不替用户下结论。

固定动作词：

- 找：从过去找原文；
- 对：把不同时间放在一起；
- 问：指出还缺什么；
- 停：证据不足时停止判断。

不做：卖萌打卡、追杀用户、医学专家造型、治愈系空话、把蘑菇图标到处重复。

## 4. 视觉语法

### 信息流封面

- 角色或核心产品证据占画面 40%—60%；
- 标题在缩略图下仍能读出“冲突”，控制在 18—26 个汉字；
- 一页只表达一个判断，正文不超过两个文字层级；不得把背景、方法、证据、结论和行动堆在同一页。
- 中文内容不再配装饰性英文翻译、英文栏目名或中英重复标题；英文只保留不可替代的产品名或证据原文。
- 固定出现 `SHROOM / 菇日记`、系列标签和“记忆管理员菇”；
- 主色使用菌丝墨绿、Brand Paper `#E9F1E1`、记忆黄绿和暖纸白；`Memory Flash` 最多占 25%，证据珊瑚最多占 5% 且只作为一个反差点；
- 一张封面只出现一个视觉隐喻，不再堆空白信息卡。

### 轮播内页

每页只完成下列一个认知任务；如果一页需要两段以上解释才成立，应拆页或删减，不得通过缩小字号容纳。

1. 第 1 页：冲突 + 角色反应；
2. 第 2 页：用户原话或具体时刻；
3. 第 3 页：旧记录、反例或缺失信息；
4. 第 4 页：真实产品截图；
5. 第 5 页：来源与用户纠正入口；
6. 第 6 页：Shroom 判断和边界；
7. 第 7 页：一个自然问题。

AI 生成图只负责无字场景、档案物件、证据线和抽象菇形轮廓；在正式 logo 源文件补齐前，不再生成或强化有表情的小脸蘑菇。产品 UI、用户行为与功能证据必须来自演示账号真实截图。中文始终确定性排版。

## 5. 热点不是第四个栏目

热点是三个栏目的选题加速层：

```text
实时信号
  → 事实与时效核验
  → Shroom 是否拥有独特真相
  → 路由到三个栏目之一
  → 角色作出反应
  → 产品证据或明确边界
```

小红书官方说明热点榜由真实搜索和互动行为计算、每分钟更新，因此热点必须记录抓取时间、来源和过期时间，不能把昨天的榜单包装成今天趋势：https://fe.xiaohongshu.com/ditto/vincent/c45978d1a53d4dec963167ebd6f1802e?fullscreen=true&naviHidden=yes

### 5.1 信号来源

优先级从高到低：

1. 小红书官方热点榜、站内搜索建议和官方活动；
2. Shroom 账号评论、收藏理由、私信问题和产品内匿名聚合问题；
3. 同品类账号近期重复问题；
4. 公开跨平台热榜与 AI/生活方式新闻；
5. 节气、开学、秋招、年终等可预期生活节点。

跨平台信号只能标为 `CROSS_PLATFORM_SIGNAL`，跨平台信号不得冒充小红书官方热点。

### 5.2 评分

| 维度 | 权重 |
|---|---:|
| 目标用户相关 | 28% |
| Shroom 独有判断 | 22% |
| 用户可参与讨论 | 14% |
| 时效性 | 14% |
| 证据质量 | 12% |
| 安全性 | 10% |

- `PURSUE`：≥78；
- `WATCH`：62—77；
- `REJECT`：<62 或触发硬停止。

### 5.3 硬停止

不利用政治与纪念事件、灾难事故、公共健康恐慌、名人私人不幸、未经核实的指控和纯吃瓜争议进行产品营销。自然内容也遵守投放规则中的真实性、不得借社会事件违规营销、不得夸张标题和不得站外导流边界：https://ad.xiaohongshu.com/next_help/docs/8dc5bd9c45c9a90cb9912f3400d43f92

## 8. v2 图像生成提示词组

三张图均使用内置图像生成，先生成无字场景，再用 SVG + Sharp 叠加中文。共同提示词已暂停作为正式对外角色规范：在正式 logo 源文件补齐前，不再强化“有表情的小脸蘑菇”。如需生成辅助底图，只生成无字、无脸、无 logo 的记忆卡片、档案盒、证据线或抽象菇形轮廓；中文标题仍必须由 SVG + Sharp 确定性排版。

三个场景变量：

1. 角色比较一张珊瑚色“当下记录”和数张绿色“过去记录”，表现新旧证据冲突；
2. 角色用放大镜检查一张空白日记卡，周围只有少量未连接线索，表现单条记录的分析边界；
3. 角色面对明亮 AI 光球，同时护住身后的个人档案卡，表现“模型更聪明不等于更懂个人”。
