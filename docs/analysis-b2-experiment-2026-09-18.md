# Shroom 日记分析 B2 实验报告（2026-09-18）

## 结论

**B2 已完成隔离实现和真实样本验证，但暂不接入生产。针对遗漏链路的 v5 最小修复也只存在于实验分支。**

B2 成功消除了旧 B 的主要 Token 膨胀，并保住了一部分理解质量；然而，它仍会随机漏掉有价值的综合理解和少量产品候选。成本与结构稳定性已经达到可继续试验的水平，内容完整性尚未达到替换 A1 的产品门槛。

生产分析路径、正式数据和历史日记均未被 B2 修改。B2 默认关闭，实验结果不进入搜索、统计、发现、身心记录、未解之问、菇卡、复利或其他正式知识。

## 实际修改

- 新增只读 `analysis-b2-experiment-v4`：五个观察席保持独立，第六次调用同时完成语义综合和完整产品候选；随后增加 `analysis-b2-experiment-v5-loss-path`，只修复已定位的最终调用输出契约与异常状态。
- 每次调用只发送一份带段落地址的完整原文，例如 `D1:P01`；地址映射仍指向原始日记版本和字符位置。
- 观察席按判断需要接收上下文：复利席接收复利方向，人生 OS 席接收有效条款，生物观察席只接收有效且未被取代的原始记录；菇卡、问题和全部方向不再默认广播给所有席位。
- 观察最低字段改为陈述、信息性质和来源地址；人物、时间、替代解释、缺失信息和置信度按需出现。
- 每席最多两条、首屏主要理解最多两条、补充理解最多两条；服务端拒绝超限结果，不通过静默截断伪装成功。
- 产品候选仍从完整原文独立判断，并复用现有菇卡、身心、未解之问和复利关联的正式校验器。
- A1 对照也经过同一套候选校验器，避免把无效 ID、无原文依据或低置信候选算作 A1 的产品能力。
- 实验记录补齐缓存命中、缓存未命中、推理 Token 和分阶段耗时字段。
- JSON 解析器允许单个完整 JSON 外带普通说明文字，字符串内部的花括号不会破坏边界判断；若出现第二份完整 JSON，则以 `SHROOM_AI_JSON_AMBIGUOUS` 明确失败，不再静默采用第一份结果。

## 实验范围

- 私密历史日记 20 篇：关系 4、工作 3、健康 3、财务 1、积极经历 3、普通经历 3、多主题 3。
- A1 与 B2 使用相同模型、相同日记、相同重建上下文和相同六次调用范围。
- 每篇均包含待办、菇卡、身心记录、未解之问和复利关联的完整候选判断。
- 全量结果属于基于重建上下文的对照，不声称精确复现历史生产时刻。
- 四个关键样本另各运行三次，用来检查同输入下的稳定性。
- 私密原文、请求和完整输出只保存在 Git 忽略目录 `server/.local/analysis-b2/`，权限为 `0600`。

原表中的“20/20 成功”只表示请求和处理流程完成，不表示满足完整输出契约。B2 v4 有 10 次缺少必需的 `synthesis` 字段，归一化又把缺失伪装成空数组；它们应计为契约失败，不能计为模型主动返回空综合。完整结构中明确返回空数组、缺少必需字段和出现歧义 JSON，必须分别统计。

B2 相比 A1：输入 Token 下降 22.8%，输出 Token 下降 16.8%，总 Token 下降 21.7%，估算费用下降 19.4%，平均耗时下降 13.8%。

B2 相比旧 B：总 Token 下降 59.5%，估算费用下降 69.0%，平均耗时下降 51.3%。旧 B 当时没有记录缓存明细，因此旧 B 的费用比较只能作为公开单价估算，不能当作账单实收差异。

本轮 A1 和 B2 的输入缓存命中分别为 99,570 和 76,409 Token，推理 Token 都为 0。上述数字也再次说明：Token 数、费用和耗时是三个不同指标，不能互相替代。

## 理解质量复核

以下判断由 Codex 对真实原文、旧 B 和 B2 输出逐项复核，尚未替代真实用户的匿名盲评。

### 明显保住或改善的部分

- 关系样本：保住了知行落差，以及“回避亲友”和“仍想重建联系”可以同时成立的区别；旧 B 的七条重复说明被合并为两条。
- 工作样本：区分了可改变的灰度测试失误与“人类天生反感更新”这一未经验证的普遍归因。
- 健康样本：把激素、多巴胺等解释保留为待验证假设，没有升级为医学事实。
- 积极/困惑样本：区分了自我标签、情境感受和已经形成但尚未执行的行动判断。
- 多主题样本：能同时保留评价预判、发布目的和状态变化，不因首屏上限丢掉问题候选。

### 明确退步或仍不稳定的部分

- 全量 20 篇中，B2 v4 最终对象有 10 篇显示为空综合。后续逐阶段审计发现，这 10 篇的模型原始根对象全部缺少 `synthesis` 字段，并非模型明确返回了空数组；归一化代码把字段缺失伪装成了合法空结果。因此旧报告中的“10 篇空综合”不能解释为模型认为没有理解价值。
- 四个关键样本各运行三次后，关系样本 3/3 有综合；工作样本 2/3 有综合；健康样本 2/3 有综合；多主题样本只有 1/3 有综合。同一输入的理解保留仍有明显波动。
- 一篇明确写到体重变化的日记，身体观察在关键复跑中只成功保留 2/3。即使总身心候选数没有下降，也不能用其他更多候选抵消这条具体遗漏。
- B2 全量生成 4 个待办、6 个菇卡候选、76 条身心结构项和 27 个未解之问；A1 分别是 11、10、71、31。数量差异不直接代表质量，但人工复核确认 B2 至少漏过一条原文明确表达的联系行动。另一方面，A1 也把部分原则或模型建议过度转成了待办，因此不能简单要求 B2 追平数量。
- 综合输出已能合并大部分同义判断，但“是否应该为空”仍被模型随机性显著影响；降低温度只改善了一部分案例，没有解决根因。

## 遗漏路径定位与最小修复

本轮没有再建 B3，也没有重跑全部版本。先对已有失败日志逐层检查，再冻结五个观察席，只重放第六次调用。

| 失败类型 | 实际请求 | 模型原始返回 | 解析/字段转换 | 业务校验 | 最早丢失位置 |
| --- | --- | --- | --- | --- | --- |
| 10 个“空综合” | 完整原文和观察席均存在 | 10/10 根对象缺少整个 `synthesis`，只返回产品候选字段 | JSON 可解析 | 归一化把缺失字段转成空数组 | 第六次调用选择了候选-only 输出契约；随后又被归一化掩盖 |
| 体重变化 | 原文明确进入请求 | 关键复跑 1/3 未生成身体观察，2/3 已生成 | 已生成的 2 次均保留 | 已生成的 2 次均保留 | 模型生成阶段，不是校验器 |
| 联系行动 | 原文进入请求 | 旧 B2 原始 `todoCandidates=[]` | 无丢失 | 无丢失 | 模型生成阶段；但 A1 的另一条联系待办属于过度生成，不能整体放宽门槛 |
| 第二份 JSON | 历史日志没有保存原始响应文本 | 历史实例无法追溯 | 旧解析器会静默取第一份 | N/A | 历史结果为“未定位”；代码层风险已被独立测试确认 |

根因是第六次调用同时包含两个相互竞争的输出契约：既嵌入了生产候选的“只返回 JSON”结构，又在末尾要求额外加入 `synthesis`。模型在一半样本中完整遵循了较早的候选-only 结构。最小修复为：规则继续复用，但只保留一个统一根对象契约，并明确“综合可以采纳、合并观察席的有效理解，不要求创造第六种新观点”。同时：

- 缺少 `synthesis` 现在是 `MISSING_REQUIRED_FIELD`，不能再变成正常空数组；明确返回空数组才是 `EXPLICIT_EMPTY`。
- 候选日志分别记录 `NOT_GENERATED`、`PRESERVED`、`FILTERED_PARTIAL` 和 `FILTERED_ALL`，可以区分模型没生成与校验器删除。
- 多份完整 JSON 现在记为 `AMBIGUOUS_JSON`；单个 JSON 后的普通文字仍可容错。
- 新增冻结重放脚本，只重放存档的第六次请求，不重新生成观察席，也不会写入正式数据。

### 冻结第六次调用的验证

- 两个原来缺失 `synthesis` 的真实失败样本：修复后 6/6 次都返回完整 `synthesis`。
- 原本正确非空的关系对照样本：3/3 次保持完整综合，没有因修复退步。
- 原本偶发漏掉体重观察的真实样本：3/3 次保留身体观察。
- 同一关系样本中的行动意图：3/3 次生成联系候选；未通过增加输出数量或放宽校验实现。
- 明确正控制“体重 80→77、明天联系小王”：3/3 次同时保留身体观察和行动候选。
- 普通散步负控制：3/3 次为明确空综合，且待办、身体观察、问题、复利关联和菇卡候选均为空。
- 以上调用都返回单个 JSON；没有出现歧义 JSON。

该结果证明已定位的结构冲突和空值掩盖得到修复，也证明正确空输出仍被保留；它不等于 B2 已完成全产品质量验证。原有 20 篇成本数据仍属于 v4，不能冒充 v5 的全量成本或质量结论。

未改写的三组原文、A1、旧 B、B2 v4 与 v5 冻结重放结果保存在私密文件 `server/.local/analysis-b2/20260918-loss-path/actual-output-comparison.json`，权限 `0600`，不进入 Git。

## 结构、状态和纵向验证

- 317 项服务端测试全部通过；本轮新增了缺失综合、显式空综合、歧义 JSON、候选过滤阶段和冻结重放测试。
- 单份原文与地址映射、按需上下文、可选观察字段、上限拒绝、完整候选校验、尾随 JSON 解析均有回归测试。
- 用户采纳状态与信息性质分离：实验观察和综合统一保持 `UNREVIEWED`，不会因为模型输出或用户未来采纳而自动升级为事实。
- B2 是纯只读函数，不创建正式待办、菇卡、身心记录、未解之问、复利进度或关系结论；重复运行不会写入或累计正式状态。
- 纵向上下文会排除无效来源、已被纠正/取代的记录和模型衍生解释，只允许仍有效的原始记录进入相关历史上下文。
- 不存在的历史上下文只能解释为“本次信息不足”，不能生成“过去从未发生”的结论。

**不上线，不部署到 `https://shroom.evox.run/` 的生产分析路径。**

B2 v5 已修复本轮明确定位的结构冲突，并在冻结失败样本中恢复了综合、身体观察和明确行动；但这只是有针对性的修复证据，不是全量上线证据。当前代码与私密对照结果保留在实验分支，供后续匿名人工校准；正式 A1 路径维持不变。
