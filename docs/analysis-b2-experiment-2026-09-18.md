# Shroom 日记分析 B2 实验报告（2026-09-18）

## 结论

**B2 已完成隔离实现和真实样本验证，但暂不接入生产。**

B2 成功消除了旧 B 的主要 Token 膨胀，并保住了一部分理解质量；然而，它仍会随机漏掉有价值的综合理解和少量产品候选。成本与结构稳定性已经达到可继续试验的水平，内容完整性尚未达到替换 A1 的产品门槛。

生产分析路径、正式数据和历史日记均未被 B2 修改。B2 默认关闭，实验结果不进入搜索、统计、发现、身心记录、未解之问、菇卡、复利或其他正式知识。

## 实际修改

- 新增只读 `analysis-b2-experiment-v4`：五个观察席保持独立，第六次调用同时完成语义综合和完整产品候选。
- 每次调用只发送一份带段落地址的完整原文，例如 `D1:P01`；地址映射仍指向原始日记版本和字符位置。
- 观察席按判断需要接收上下文：复利席接收复利方向，人生 OS 席接收有效条款，生物观察席只接收有效且未被取代的原始记录；菇卡、问题和全部方向不再默认广播给所有席位。
- 观察最低字段改为陈述、信息性质和来源地址；人物、时间、替代解释、缺失信息和置信度按需出现。
- 每席最多两条、首屏主要理解最多两条、补充理解最多两条；服务端拒绝超限结果，不通过静默截断伪装成功。
- 产品候选仍从完整原文独立判断，并复用现有菇卡、身心、未解之问和复利关联的正式校验器。
- A1 对照也经过同一套候选校验器，避免把无效 ID、无原文依据或低置信候选算作 A1 的产品能力。
- 实验记录补齐缓存命中、缓存未命中、推理 Token 和分阶段耗时字段。
- JSON 解析器可安全读取模型返回的第一个完整 JSON；尾随第二段 JSON 或文字不再触发一次昂贵重试，字符串内部的花括号不会破坏边界判断。

## 实验范围

- 私密历史日记 20 篇：关系 4、工作 3、健康 3、财务 1、积极经历 3、普通经历 3、多主题 3。
- A1 与 B2 使用相同模型、相同日记、相同重建上下文和相同六次调用范围。
- 每篇均包含待办、菇卡、身心记录、未解之问和复利关联的完整候选判断。
- 全量结果属于基于重建上下文的对照，不声称精确复现历史生产时刻。
- 四个关键样本另各运行三次，用来检查同输入下的稳定性。
- 私密原文、请求和完整输出只保存在 Git 忽略目录 `server/.local/analysis-b2/`，权限为 `0600`。

### 分阶段结果

| --- | ---: | ---: | --- |
| 五个观察席合计 | 124,648 | 121,297 | 基本持平；地址协议增加了一些输入，但可选字段和低随机度减少了输出 |

## 理解质量复核

以下判断由 Codex 对真实原文、旧 B 和 B2 输出逐项复核，尚未替代真实用户的匿名盲评。

### 明显保住或改善的部分

- 关系样本：保住了知行落差，以及“回避亲友”和“仍想重建联系”可以同时成立的区别；旧 B 的七条重复说明被合并为两条。
- 工作样本：区分了可改变的灰度测试失误与“人类天生反感更新”这一未经验证的普遍归因。
- 健康样本：把激素、多巴胺等解释保留为待验证假设，没有升级为医学事实。
- 积极/困惑样本：区分了自我标签、情境感受和已经形成但尚未执行的行动判断。
- 多主题样本：能同时保留评价预判、发布目的和状态变化，不因首屏上限丢掉问题候选。

### 明确退步或仍不稳定的部分

- 全量 20 篇中，B2 有 10 篇返回空综合。空结果本身合法，但人工复核发现财务和普通经历至少两篇仍有旧 B 已经识别出的重要且不同的理解，因此不能把这 10 篇全部视为正确克制。
- 四个关键样本各运行三次后，关系样本 3/3 有综合；工作样本 2/3 有综合；健康样本 2/3 有综合；多主题样本只有 1/3 有综合。同一输入的理解保留仍有明显波动。
- 一篇明确写到体重变化的日记，身体观察在关键复跑中只成功保留 2/3。即使总身心候选数没有下降，也不能用其他更多候选抵消这条具体遗漏。
- B2 全量生成 4 个待办、6 个菇卡候选、76 条身心结构项和 27 个未解之问；A1 分别是 11、10、71、31。数量差异不直接代表质量，但人工复核确认 B2 至少漏过一条原文明确表达的联系行动。另一方面，A1 也把部分原则或模型建议过度转成了待办，因此不能简单要求 B2 追平数量。
- 综合输出已能合并大部分同义判断，但“是否应该为空”仍被模型随机性显著影响；降低温度只改善了一部分案例，没有解决根因。

## 结构、状态和纵向验证

- 313 项服务端测试全部通过。
- 单份原文与地址映射、按需上下文、可选观察字段、上限拒绝、完整候选校验、尾随 JSON 解析均有回归测试。
- 用户采纳状态与信息性质分离：实验观察和综合统一保持 `UNREVIEWED`，不会因为模型输出或用户未来采纳而自动升级为事实。
- B2 是纯只读函数，不创建正式待办、菇卡、身心记录、未解之问、复利进度或关系结论；重复运行不会写入或累计正式状态。
- 纵向上下文会排除无效来源、已被纠正/取代的记录和模型衍生解释，只允许仍有效的原始记录进入相关历史上下文。
- 不存在的历史上下文只能解释为“本次信息不足”，不能生成“过去从未发生”的结论。

## 历史关联只读审计

- 全库 `ACTIVE` 的人生 OS / 复利 AI 关联：0；
- 未经用户确认却为 `ACTIVE` 的 AI 关联：0；

## 上线判断

**不上线，不部署到 `https://shroom.evox.run/` 的生产分析路径。**

B2 已证明可以去掉旧 B 的大部分材料膨胀，并在若干关键案例中保住理解进步；但它还没有证明能稳定保留 A1 的完整产品能力，也没有稳定保住旧 B 在财务、普通经历和多主题记录中的有效理解。当前代码与私密对照结果保留在实验分支，供后续匿名人工校准；正式 A1 路径维持不变。
