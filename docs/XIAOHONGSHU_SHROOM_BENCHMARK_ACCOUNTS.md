## 2. 为什么没有选择游戏官方号

游戏账号的数据可以很强，但大部分增长依赖既有角色、剧情更新、玩家关系、赛事和二创生态。Shroom 当前没有这些资产，模仿其画面、语气或追热点方式很容易得到“像内容、但不像产品”的结果。因此游戏账号只留作娱乐节奏观察，不进入正式学习池。

```text
IP 人格：多邻国 + 寿司郎
产品证据：Apple + 百度地图

官方人话：支付宝 + 滴滴
专业可信：丁香园
社交回流：TapNow
```

Shroom 不复制账号整体，而是把一个模块放进一次受控实验。每次必须保持客群、产品事实和互动问题不变，只改变一个内容机制。

## 4. 对 Shroom 首轮内容的直接翻译

### 路线一：菇的记忆人格

组合多邻国的稳定角色与蚂蚁森林的长期积累，但不催打卡：

> “你三个月前写过一句话，今天的菇替你找回来了。”

角色只做三件事：记住、找到、提醒。它不诊断、不训斥、不替用户决定。

### 路线二：真实产品时刻

组合 Apple 与百度地图：不用概念海报，直接展示一个发生时刻、一次检索、原文证据和用户能做的下一步。

### 路线三：可信的身心观察

组合丁香园与种草学习薯：解释一个专业概念、指出日记证据、同时说明反证、缺失信息和“这不是诊断”。

### 路线四：让真实内容产生关系

组合 TapNow、支付宝与滴滴：用户明确授权后，把私人记录转成不泄露隐私的真实表达；评论中的具体问题进入下一篇内容，而不是诱导点赞收藏。
