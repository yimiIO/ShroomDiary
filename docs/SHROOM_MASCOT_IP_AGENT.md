# Shroom 卡通 IP 角色 Agent 决策

> 版本：2026-09-18 v1  
> 状态：内部角色方向审查，未发布  
> 触发原因：商标级图形方向过于抽象，缺少多邻国和游戏官方号那种可持续运营的卡通角色感。

## 1. 先纠正方向

上一轮“商标图形”解决的是可识别、可缩小、可注册的问题；但它不能直接承担小红书获客。

Shroom 官方号真正需要的是一个 **可连续演内容的卡通 IP**：

- 一眼能看出是同一个角色；
- 有脸、有动作、有情绪；
- 能做表情包、封面、评论回复和热点反应；
- 能把抽象的“AI 日记 / 个人数据库 / 记忆回看”变成具体行为。

所以 Shroom 应该采用双层品牌结构：

| 层级 | 任务 | 风格 |
|---|---|---|
| Logo / 商标 | 注册、防守、App icon、正式识别 | 简洁、结构独特、少表情 |
| 卡通 IP | 小红书、公众号、表情包、热点反应、用户互动 | 卡通、人格强、动作连续 |

卡通 IP 可以贴合头像，但不等同于商标。它可以更活、更夸张、更有戏。

## 2. 向多邻国和游戏账号学什么

Shroom 不复制猫头鹰、游戏角色或二创生态，只学习它们的机制：

1. **固定角色**：每篇内容都让同一个角色出场，而不是每次换一套漂亮图。
2. **固定行为**：角色不是摆拍，而是反复做几件事。
3. **强表情**：角色要能怀疑、震惊、偷看、翻旧账、得意、沉默。
4. **低成本复用**：同一角色可以换姿势、换道具、换标题，不需要每篇重新发明美术。
5. **评论人格**：官方号回复用户时像角色在说话，而不是公司公告。

对 Shroom 来说，角色的固定行为不是催打卡，而是：

- 找：从旧日记里找证据；
- 对：把今天和过去对上；
- 问：追问一个未解之问；
- 停：提醒这不是诊断、不是结论；
- 推：把一个发现变成下一步行动。

## 4. 品牌 Agent 推荐

主线建议不是四选一，而是一个角色的四种状态：

> **主角色：记忆管理员菇**  
> 基础人格：A 记忆侦探菇  
> 可爱表达：B 日记捣蛋菇  
> 可信表达：C 安静档案菇  
> 行动表达：D 成长冲刺菇

这样既能有统一 IP，又能覆盖不同内容场景。

## 5. 角色设定

### 名字

暂定：**记忆管理员菇**

可以口语化叫：

- 小菇；
- 菇菇；
- 翻旧账菇；
- 证据菇。

正式账号中优先用“小菇”，因为更口语、更适合评论区。

### 性格

- 不是治愈系软萌，而是“温柔但很会翻旧账”；
- 不替用户下结论，但会拿出过去的证据；
- 有点烦，但烦得有用；
- 不说“我比你懂你”，只说“你以前写过这个”。

### 口头禅候选

- “等下，你以前写过。”
- “先别急着下结论，我找找证据。”
- “这不是诊断，是线索。”
- “你不是没答案，你是忘了证据放哪了。”
- “旧日记不是过去，它可能是今天的说明书。”

## 6. 视觉规则

必须保留：

1. 深森林绿菌盖；
2. 暖白身体；
3. 记忆黄绿发光道具；
4. 右上角便签 / 日记卡片 / 档案纸；
5. 黑色大眼睛和明显眉毛；
6. 一个明确动作。

必须避免：

1. 像普通蘑菇头像一样只是站着笑；
2. 像医疗助手、心理医生或专家；
3. 像游戏角色战斗化；
4. 复制多邻国猫头鹰的轮廓、眼睛和压迫式催促；
5. 只有可爱，没有产品行为。

## 7. 和商标的关系

卡通 IP 不替代商标图形。

- 商标图形负责正式识别；
- 小菇负责获客、内容、情绪和互动；
- 两者共享颜色、菇形、记忆标签和 S / 证据线等结构；
- 未来商标注册通过后，再把商标结构反向植入小菇的帽子、胸章或道具。

## 8. 下一步

1. 优先深化 A + B：记忆侦探菇与日记捣蛋菇；
2. 做 12 个基础表情：怀疑、震惊、偷看、得意、沉默、翻找、举证、提醒、拒绝诊断、催用户确认、找到线索、摊手；
3. 做 3 张小红书封面测试：日记回忆、身心线索、未解之问；
4. 用户审核后再决定是否进入正式公众号 / 小红书头像候选。
