# Shroom 小红书运营 Agent 系统

> 版本：2026-09-18 v2  
> 当前范围：首轮 3 篇自然图文测试  
> 目标：验证“写了很多，却无法在需要时调用过去”是否是目标用户愿意具体表达的问题

## 1. 顶级方案给出的共同结论

对 Jasper、HubSpot、Salesforce、Adobe 以及通用 Agent 工程方法的分析显示，高质量营销 Agent 不是一个能随意写文案和自动发帖的万能机器人，而是一条有共享上下文、专业分工、真实反馈和人类门禁的工作流：

- Jasper 把 Agent 绑定到内容流水线中的具体工作，并共享品牌、受众、产品知识与治理规则；
- HubSpot 的社交媒体 Agent 会同时使用历史表现、品牌语气、受众、价值主张和业务背景；
- Salesforce 从结构化 Campaign Brief 开始，内容由品牌与数据约束，发布前保留人工审阅；
- Adobe 强调只允许已批准素材进入激活环节；
- OpenAI 与 Anthropic 的 Agent 指南都建议先用简单、可组合、可观察的 Manager 工作流，并为高风险动作保留人工确认。

Shroom 采用以下结构：

```text
运营总管
  → 用户洞察与选题
  → 小红书目标用户信号分析
  → 小红书热点雷达（可选加速层）
  → 内容主编与证据装配
  → 小红书内容生成
  → 内容事实与合规（独立门禁）
  → CEO 批准
  → 新媒体运营发布
  → 社群承接
  → 数据归因与复盘
```

分析者不生成最终稿，生成者不评价自己的结果，发布者不得修改已批准事实，事实与合规角色不受增长指标支配。

## 2. 运营总管 Agent

### 唯一使命

围绕一个明确目标用户和一个真实痛点，协调专业 Agent，把已验证产品事实转成最小、可逆、可归因的渠道实验，并根据真实行为决定继续、修改或停止。

### 固定输入

- CEO 当前批准范围；
- 目标用户、排除人群和具体发生时刻；
- 用户要完成的 Job；
- 已验证产品能力、演示素材和来源状态；
- 带 URL、查询词和时间的公开用户语言；
- 历史渠道数据、归因边界与平台规则；
- 所有事实的 `VERIFIED / UNVERIFIED` 状态。

### 固定输出

每轮只生成一份实验简报：唯一阻断点、目标用户、原话式痛点、唯一假设、产品证据、内容变量、平台形式、单一动作、来源表、成功/未知/停止条件、归因方式和 CEO 决策项。

### 权限边界

- 可以：只读研究、内部简报、实验设计、草稿调度、运行记录；
- 需 CEO 批准：发布、删除、回复、私信、达人联系、投放、预算、账号资料变化和真实用户案例；
- 永久禁止：读取未授权私密日记、伪造用户或数据、刷量互赞、医疗诊断、焦虑操纵、规避平台导流规则和承诺“爆文/不限流”。

### 结果定义

至少取得一条可复核的目标用户具体表达、一项合规激活，或一个证据充分的 `STOP / UNKNOWN` 结论。稿件数量和曝光量不是结果。

## 3. 小红书标杆与目标用户信号分析 Agent

> 对外可简称“爆文分析 Agent”，内部正式名称不用“爆文”作为目标。

### 两种模式必须分开

#### `ACCOUNT_BENCHMARK`

验证今年哪些官方账号仍在持续获得流量信号，以及哪些机制值得进入 Shroom 的单变量实验。账号增长不能直接写成单篇爆文，第三方榜单不能直接推出内容因果。

#### `POST_EVALUATION`

判断 Shroom 某篇内容是否让目标用户认出自己的真实问题，并产生可验证的下一步行为。

### 标杆研究硬门槛

- 账号身份可核验，并保留来源 URL 与观察日期；
- `CURRENT_SUSTAINED` 至少覆盖今年 3 个不同月份、最近 2 个连续窗口，且最新快照不超过 14 天；
- `YEAR_REPEAT`、`RECENT_REPEAT` 和 `WATCHLIST` 必须与 `CURRENT_SUSTAINED` 分开；
- 第三方粉丝增长榜只证明账号趋势，不证明自然流量、曝光或某篇笔记的因果；
- 单篇爆文必须直接审计笔记，记录发布时间、可见互动快照、账号自身基线与多个观察节点；
- 来源顺序固定为：小红书直接页面 → 小红书一方数据 → 可回溯的第三方时间序列 → 媒体/服务商案例；最后一类不能独立成为结论；
- 输出必须包含可迁移机制、不可迁移资产、不确定性和下一次补证动作。

### Shroom 内容发布后必须做

- 发布前锁定内容编号、唯一假设、固定变量和停止条件；
- 发布后读取一方平台数据、匿名化评论和合规归因；
- 区分分发、目标用户表达、产品激活和噪声；
- 输出 `CONTINUE / ITERATE / STOP / UNKNOWN` 及证据；
- 把用户原话回流到下一轮选题和产品判断。

### 100 分证据评分

| 维度 | 分值 | 有效证据 |
|---|---:|---|
| 目标用户命中 | 20 | 明确说明自己长期记录及存储方式 |
| 痛点具体性 | 25 | 描述过去写的内容很少再用、找不到旧记录或重复问题仍从零思考 |
| 原因机制共鸣 | 15 | 能复述“按日期保存、按问题重复”等机制 |
| 高意图行为 | 15 | 说明替代方案、提出具体问题或愿意测试 |
| 信任与证据 | 10 | 追问原文依据、隐私、授权和不确定性 |
| 内容消费与分发匹配 | 10 | 目标流量来源及相对自身基线改善 |
| 合规首次价值激活 | 5 | 注册后首次从过去记录中找出一条相关内容 |

合规是独立硬门槛，不能被高分覆盖。没有至少一条可复核的目标用户具体表达，最高只能是 `NONE`；分发样本不足必须是 `UNKNOWN`，不能宣布“没有需求”。

### 禁止误判

不得把曝光、点赞、收藏、搜索流量、注册或单篇成功分别等同于需求、激活或可复制栏目。创始人、员工、朋友、合作方、抽奖、付费流量、互赞和异常集中互动必须剔除或单列。

首轮账号研究、证据等级与来源台账见 [`XIAOHONGSHU_BENCHMARK_RESEARCH.md`](./XIAOHONGSHU_BENCHMARK_RESEARCH.md)。
面向 Shroom 官方账号的 10 个正式学习对象、模块分工和模仿边界见 [`XIAOHONGSHU_SHROOM_BENCHMARK_ACCOUNTS.md`](./XIAOHONGSHU_SHROOM_BENCHMARK_ACCOUNTS.md)。
深度适配审计、flomo 对照、单主号三栏目架构与拆号门槛见 [`XIAOHONGSHU_DEEP_RESEARCH_AND_ACCOUNT_STRATEGY.md`](./XIAOHONGSHU_DEEP_RESEARCH_AND_ACCOUNT_STRATEGY.md)。

### 热点雷达不是爆文许愿机

热点雷达只在选题阶段工作：记录来源、抓取时间、来源类型和有效期，用目标用户相关、Shroom 独有判断、讨论参与、时效、证据质量与安全六个维度评分，再路由到现有三个栏目。它不写最终稿、不批准自己的候选、不发布，也不能把跨平台热榜冒充小红书站内热点。

- `PURSUE`：≥78；
- `WATCH`：62—77；
- `REJECT`：<62 或触发硬停止；
- 政治与纪念事件、灾难事故、公共健康恐慌、名人私人不幸和未经核实指控直接停止；
- 热点只提供进入角度，真实产品证据仍然必需；
- 完整规则与当日干跑见 [`XIAOHONGSHU_HOTSPOT_AND_VISUAL_SYSTEM.md`](./XIAOHONGSHU_HOTSPOT_AND_VISUAL_SYSTEM.md)。

## 4. 小红书内容生成 Agent

### 唯一使命

把已锁定的实验简报和已验证证据转成小红书原生候选稿，不改变目标用户、产品承诺、事实状态和实验变量。

### 必需输入

- 内容编号与唯一假设；
- 锁定的目标用户、痛点和单一互动问题；
- 可使用产品证据、授权状态和禁止陈述；
- Shroom 品牌语气和版式规范；
- 平台规范、AI 标识和停止条件。

### 固定输出

封面、7 页图文脚本、正文、标签、单一互动问题、逐页素材来源、AI 标识、风险点和停止条件。任何未经验证的功能或数据必须标为占位，不能写成已上线事实。

### 权限边界

不能读取真实用户私密日记，不能发布、回复、私信或投流，不能给自己的内容评分，不能绕过内容事实与合规 Agent。每个发布候选必须由人类完成最终事实确认。

## 5. 图文视觉生产链

小红书图文不由一个模型从文案直接生成成品。正式生产链为：

1. **视觉导演 Agent**：把 7 页拆成逐页认知任务、信息层级和 storyboard；
2. **视觉素材生成 Agent**：只生成无文字插画、背景和隐喻素材；真实产品能力只用真实截图；
3. **图文排版 Agent**：使用 SVG + Sharp 确定性渲染中文、页码和品牌元素，输出 1080×1440 PNG；
4. **视觉质检 Agent**：独立检查错字、溢出、安全区、对比度、页面顺序、示意图标识和 AI 声明；
5. **内容事实与合规 Agent**：确认视觉没有扩大原文承诺或伪装产品功能；
6. **新媒体运营 Agent**：只能发布全部门禁通过且由 CEO 批准的版本。

工具选择：

- 选题、storyboard 与文案：受控语言模型 Agent；
- 插画、背景与隐喻素材：图像生成模型，只输出无文字素材；
- 中文文字与版式：SVG + Sharp，保证文字准确、尺寸稳定和可复现；
- 产品证据：真实演示账号截图，不让图片模型伪造 UI；
- 质检：文件尺寸/顺序自动检查 + 人工逐页视觉检查；必要时增加 OCR 复核。

首轮纯编辑图形虽然可读，但缺少信息流停留和跨篇品牌识别，已停止作为官方号封面方案。v2 固定使用“记忆管理员菇”作为连续主角：深森林绿不对称菌盖、荧光记忆标签、暖白身体与略带怀疑的眉毛；固定动作是找、对、问、停。AI 图像只生成无字角色场景，中文继续确定性排版，产品证据继续使用真实演示截图。

## 6. 首轮实验控制

三篇固定同一目标用户、核心承诺、7 页形式、演示账号、隐私边界、统一讨论问题、AI 标识和 7 天观察窗；分别验证三个官方栏目：

1. `xhs-past-helps-today-001`：旧记录与反例能否证明“过去今天有用”；
2. `xhs-one-diary-finds-001`：事实、可能性和缺失信息能否建立信任；
3. `xhs-building-shroom-001`：公开真实产品取舍能否让用户认同 Shroom 的判断标准。

不投流、不发动关系人互动、不诱导点赞收藏、不放站外联系方式。观察节点为发布后 `2h / 24h / 72h / 7d`，不能因 2 小时数据随意改稿。
