## 对照原则

三版使用相同封面文案、相同 3:4 画布和相同 Shroom 色彩边界，只改变视觉生产方法。任何一版都不能用生成画面冒充真实产品界面或用户记录。

## 三种方法

| 方案 | 生产方法 | 原生感 | 品牌辨识度 | 信息控制 | 证据可信度 | 适用场景 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| A | SVG + Sharp 确定性编辑设计 | 3/5 | 3/5 | 5/5 | 4/5 | 证据页、隐私边界、解释性内容 |
| B | AI 编辑摄影底图 + 确定性中文排版 | 5/5 | 4/5 | 4/5 | 3/5 | 首轮痛点获客封面、日记场景 |
| C | AI 抽象记忆视觉 + 确定性中文排版 | 4/5 | 5/5 | 4/5 | 2/5 | 品牌远景、记忆与长期陪伴主题 |

“证据可信度”只评价当前封面本身。补入真实演示账号截图、原文来源和纠错入口后，完整图文的证据可信度需要重新评估。

## 首轮实际选择

- 首轮曾统一使用 A，以减少画风变量；人工审阅发现它“可读但像产品说明书”，缺少信息流停留、角色态度和官方号连续识别，因此不再作为发布候选。
- 已生成 `xhs-past-helps-today-001`、`xhs-one-diary-finds-001`、`xhs-building-shroom-001` 三套共 21 页 1080×1440 PNG。
- 版式、安全区、中文准确性和栏目区分已人工检查通过；manifest 仍保持 `publishReady: false`。
- 发布前必须把关键示意页补成演示账号真实截图，并重新执行事实与合规门禁。
- C：保留给“个人记忆如何重新连接”“AI 长期伙伴”一类品牌主题，不作为第一篇功能证明。
- 不建议整套轮播全部使用 AI 生图。生成图负责吸引，真实界面和记录负责说服。

## v2 最终方向：固定 IP + 确定性排版

官方号固定主角为“记忆管理员菇”，不是每篇随机生成一种蘑菇：深森林绿不对称菌盖、右侧荧光记忆标签、暖白身体、黑色椭圆眼睛和怀疑眉毛。每张封面只允许一个冲突、一个角色动作和一句判断，连续复用“找、对、问、停”四种动作语言。

三张 v2 封面位于 `artifacts/xiaohongshu/shroom-official-visual-v2/`。AI 只负责无字角色场景，中文由 SVG + Sharp 叠加；内页仍需补真实演示账号截图，因此 `publishReady` 保持 `false`。完整规则见 [`XIAOHONGSHU_HOTSPOT_AND_VISUAL_SYSTEM.md`](./XIAOHONGSHU_HOTSPOT_AND_VISUAL_SYSTEM.md)。

## 可选 Skill / Agent 路线

1. `imagegen`：生成无文字的摄影、插画或抽象视觉资产；不能负责中文排版和产品事实。
2. `surfplus-xiaohongshu-carousel` 的证据型方法：一篇只解决一个怀疑，优先真实截图、原文、来源和反例；在 Shroom 中只复用方法，不继承 SURFPLUS 品牌。
3. `Canva Bulk Create + Brand Check`：适合批准模板后的批量改稿、多人协作和可编辑交付；它提高生产效率，不替代证据门禁。
4. Shroom 自有 Agent 链：信号分析 → 内容生成 → 视觉导演 → 素材生成 → 确定性排版 → 独立视觉质检 → 内容合规 → 人工发布。

> 3:4 小红书封面底图；表达“过去的个人记录在问题再次出现时重新派上用场”。半透明档案层、无字纸卡和细线连接，一张被找回的发光记录成为焦点。高级极简纸雕与半透明材质，深炭绿、柔和奶油色、浅黄绿色和少量珊瑚色；左上保留标题空间。不得出现文字、数字、Logo、界面、人物、蘑菇符号、霓虹科幻或水印。
